# Aurora Strike Blender source

`aurora_strike_assets.blend` is generated by `tools/generate_shooter_models.py` in GitHub Actions with Blender 4.3.2.

The scene contains an inspectable gallery of all twelve launch weapons, the tactical operator, a cargo container, and a cover crate. Every mesh and material is created procedurally from primitives by this repository's generator. It uses no downloaded models, textures, or other third-party art.

Do not commit Blender rolling backups (`.blend1`, `.blend2`). Regenerate the canonical source and GLB exports through the asset workflow after changing the generator.
