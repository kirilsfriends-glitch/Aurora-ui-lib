# Aurora Strike Blender source

`aurora_strike_assets.blend` is generated by `tools/generate_shooter_models.py` with Blender 4.3.2.

The vertical-slice source contains one authored tactical environment, four tuned weapons, and the operator model. Dockyard is built as a deliberate three-lane combat space rather than a random arrangement of runtime boxes. All geometry and PBR-style materials are produced by this repository's generator; no downloaded models or textures are included.

The generated `.blend` is an inspectable source gallery. Runtime GLBs are exported to `game/models/`. Blender rolling backups (`.blend1`, `.blend2`) remain ignored.
