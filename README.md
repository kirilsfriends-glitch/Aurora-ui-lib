# Aurora Strike: Mobile

**Aurora Strike: Mobile** is an original offline 3D first-person tactical shooter for Android and desktop, built from scratch with Godot 4.3 and Blender 4.3. It replaces the former Aurora Drift demo in this repository.

## Launch content

- **5 maps:** Dockyard Zero, Sandstone Citadel, Metro Nexus, Frostline Base, and Neon Labs.
- **12 weapons:** AK-47, M4A1, AWP, Scout, MP5, P90, Nova shotgun, Desert Eagle, Glock-18, USP-S, tactical knife, and frag grenade.
- **3 game modes:** Team Deathmatch, round-based Elimination, and Control.
- **5v5 offline matches:** the player joins four friendly bots against five enemy bots.
- **Map-voting lobby:** all nine bots make randomized votes and the highest-voted operation is selected.
- **Tactical AI:** vision cones, ray-tested sight, weapon hearing, investigation, AStar pathfinding, cover selection, separation, strafing, retreat/reload behavior, friendly-fire checks, and three accuracy levels.
- **Mobile-first FPS controls:** independently tracked touches support simultaneous movement, camera aim, firing, ADS, jump, crouch, reload, and weapon swapping.

## Original Blender art

All launch weapons, the tactical operator, and the principal map props are original procedural models. No third-party geometry or textures are used.

- Generator: [`tools/generate_shooter_models.py`](tools/generate_shooter_models.py)
- Editable source: `assets/blender/aurora_strike_assets.blend` (generated by CI)
- Runtime exports: `game/models/*.glb` (generated by CI)

The generator is intentionally reproducible and runs against the official Blender 4.3.2 Linux build in GitHub Actions.

## Run locally

1. Open [`game/project.godot`](game/project.godot) in Godot 4.3 or newer.
2. Import the project and run `main.tscn`.
3. Choose a mode and AI difficulty, vote for a map, and deploy.

Desktop controls: **WASD** to move, **mouse** to aim, **left click** to fire, **Space** to jump, **R** to reload, and **Q** to cycle weapons. Android uses the on-screen independent multitouch layout.

See [`game/README.md`](game/README.md) for architecture, modes, controls, and validation details.

## Android build and release

GitHub Actions:

1. generates and commits the Blender source and 15 GLB models;
2. imports the project with Godot 4.3;
3. smoke-tests all five map graphs and all twelve weapon definitions;
4. exports and verifies an arm64-v8a APK;
5. publishes the APK and SHA-256 checksum under GitHub Releases.

The game works offline and requests no custom Android permissions. Release APKs are debug-signed for direct sideloading and testing.
